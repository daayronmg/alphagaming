# Reports

Salida de los informes generados por la herramienta (JSON / CSV / HTML).

Los archivos `demo_report.*` se incluyen como **evidencia** de que el generador
de informes funciona; se producen con:

```bash
python3 WindowsApp/run_cli.py demo
```

a partir del log de ejemplo en `WindowsApp/sample_data/sample_results.json`. Son
valores ilustrativos, no medidas de ningún sistema en vivo. Otros informes que
generes aquí quedan ignorados por `.gitignore`.
